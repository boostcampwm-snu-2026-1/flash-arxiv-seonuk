Data Flow

논문 데이터 흐름

① 키워드 + 카테고리 입력
↓
② arXiv 쿼리 생성
ti:"..." OR abs:"..." OR au:"..."
↓
③ Vercel rewrite → export.arxiv.org
↓
④ Atom XML 파싱 → JS 객체
↓
⑤ 날짜별 그룹핑 후 렌더

CORS 해결

  • 개발 환경 Vite proxy
  • 프로덕션 vercel.json rewrite
{
  "rewrites": [{
    "source": "/arxiv/:path*",
    "destination": "https://export.arxiv.org/:path*"
  }]
}

Rate Limit 처리

  • 요청 간격 최소 5초
  • 429 응답 10초 대기 후 재시도
  • 재시도 횟수 최대 3회

프롬프트 설계

핵심 내용 3가지 불렛으로 요약해줘.

"- "으로 시작하는 3줄로만 답해줘.

- (두 번째 핵심 내용.)
- (세 번째 핵심 내용.)

초록: ${abstract}

Auth & Persistence

인증 & 데이터 저장

Google 로그인 (Firebase Auth)
↓
Firestore에서 사용자 데이터 로드
↓
State 복원 (keywords, saved, notes, folders)
↓
변경 감지 → 800ms debounce → Firestore 저장
↓
beforeunload → 즉시 flush

Firestore 저장 데이터

  • keywords string[]
  • categories string[]
  • saved Paper[]
  • notes Record<id, string>
  • folders Folder[]
  • paperFolders Record<id, folderId>

  • 요약 캐시 localStorage

AI에게 주는 프로젝트 헌법

# Seonuk's Interactive Research Helper

## Design System
- Theme: Gruvbox (dark/light)
  — 예외 없이 전체 적용
- Typography: Serif fonts
  — 학술 논문 느낌

## Code Style
- # 불필요한 주석 금지
- # 과도한 추상화 금지
- # API 키 하드코딩 절대 금지
  → 반드시 env vars 사용

CLAUDE.md 효과

  • 🎨테마 일관성 — 어떤 컴포넌트를 추가해도 Gruvbox 유지
  • 🔒보안 — env var 없이 API 키 하드코딩 시 AI가 스스로 거부
  • 🧹코드 품질 — 불필요한 주석, 과설계 방지
  • 📋일관된 컨텍스트 — 매 대화마다 다시 설명할 필요 없음
